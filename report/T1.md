# T1. Сравнение агентных платформ

Сравнил Hermes Agent, OpenClaw, PicoClaw и свою разработку (Jarvis)

## Архитектура

Все четыре решения можно запустить локально или на VPS. PicoClaw также рассчитан на маломощные устройства.

| Критерий | Hermes | OpenClaw | PicoClaw | Jarvis |
|---|---|---|---|---|
| Язык и установка | Python; готовый Docker-образ с библиотеками | TypeScript; нужен Node.js с npm-пакетами либо Docker | Go; один исполняемый файл либо Docker | TypeScript; сборка из исходников, нужны Node.js, PostgreSQL и Claude Agent SDK |
| Доступ к агенту | Через терминал и мессенджеры | Через терминал и мессенджеры; можно подключать другие устройства | Через терминал и мессенджеры | Через веб-интерфейс |
| Автозапуск | Docker перезапускает контейнер по `unless-stopped` | Можно установить как службу ОС; для Docker задаётся перезапуск контейнера | Нужно настроить службу ОС или перезапуск контейнера | Сервер запускается через systemd; незаконченный ответ теряется |
| Готовые возможности | Память, инструменты, навыки и задачи по расписанию | Те же возможности, плюс плагины | Память, инструменты, навыки и задачи по расписанию | Проекты, задачи, история и навыки в БД; планировщика нет |

## Ресурсы

| Показатель | Hermes | OpenClaw | PicoClaw | Jarvis |
|---|---|---|---|---|
| CPU и память | Мой VPS: 1 vCPU, 2 ГБ RAM; Docker-образ занимает около 4,6 ГБ на диске | По документации: минимум 1 vCPU и 1 ГБ RAM, рекомендуется от 2 ГБ RAM | По README: новые сборки могут занимать 10–20 МБ RAM | У службы установлен лимит 650 МБ; потребление не измерялось |
| Запуск | Измерено 23,6 с от старта контейнера до подключения Telegram; образ загружен заранее | Не измерялось | Разработчик заявляет менее 1 с на одном ядре 0,6 ГГц | Не измерялось |

## Выбор

Веса выбраны под задачу регулярного поиска источников, а не как универсальная оценка платформ.

| Критерий | Вес | Причина |
|---|---:|---|
| Расписание и доставка результата | 25% | Задача должна работать без открытого чата |
| Источники, файлы и свои навыки | 25% | Нужны поиск статей и обработка результатов |
| Ограничение доступа | 20% | Агент может выполнять команды |
| Развёртывание и журналы | 15% | Нужны постоянные данные и возможность разобрать ошибку |
| Расходы и выбор модели | 15% | Регулярные запуски расходуют квоту и бюджет |

Выбрал Hermes: в нём есть Telegram, расписание и навыки, а обработку источников можно написать на Python.

OpenClaw рассмотрел бы для задач со сложной браузерной автоматизацией и несколькими устройствами. PicoClaw рассмотрел бы для слабого оборудования после проверки нужных инструментов. Jarvis удобен для работы через веб-интерфейс, но для автономных задач ему нужно добавить расписание и доставку результатов.
