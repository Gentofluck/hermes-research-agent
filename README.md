# На полях

Hermes Agent для исследовательских задач. Задание 2 по курсу pyweb2025.

## Сервер

- Провайдер: AEZA.
- Тариф: CLTs-1.
- Регион: США.
- Стоимость: €5,93 в месяц.
- Система: Ubuntu 26.04.1 LTS.
- Ресурсы: 1 vCPU, 2 ГБ RAM, диск 30 ГБ.

## Базовая настройка

На сервере уже был пользователь `agent`, который не входит в группы `sudo` и `docker`. Вход по SSH-ключу проверен, парольный вход отключён. UFW разрешает входящие подключения только на SSH-порт `22/tcp`.

Установлены обновления, доступные через `apt-get upgrade`, затем VPS перезагружен. После перезагрузки повторно проверены доступ по ключу и правила firewall.
