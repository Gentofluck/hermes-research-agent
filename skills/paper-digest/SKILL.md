# Дайджест публикаций

Навык ищет публикации по теме из `MEMORY.md` и отбирает их по смыслу аннотаций. Запусти подготовленный сценарий:

```bash
/opt/hermes/.venv/bin/python "$HERMES_HOME/skills/research/paper-digest/scripts/digest.py"
```

По умолчанию проверяются последние семь суток. Если пользователь указал другой период, передай его через `--days`. Не расширяй период без просьбы пользователя и не запускай сценарий повторно, чтобы получить более красивый результат.

Сначала Hermes без инструментов составляет запрос arXiv. Если выдача непустая, второй запуск Hermes выбирает статьи по аннотациям. Инструкции находятся в `prompts/query.txt` и `prompts/select.txt`. Python сверяет ссылки и фрагменты аннотаций с ответом API и формирует до трёх записей с названием, авторами, датой, ссылкой и пояснением на русском.

Верни текст сценария без изменения списка и библиографических данных. При пустом отборе или ошибке тоже верни его сообщение. Не дополняй ответ статьями по памяти и не используй метку подавления доставки.

Результат и измерения сохраняются в `$HERMES_HOME/paper-digest/`. Cron запускает тот же сценарий в режиме `--no-agent`: повторная генерация текста не нужна, готовый ответ передаётся в Telegram как есть.
